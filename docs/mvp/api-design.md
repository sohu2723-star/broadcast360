API Design

Authentication
Login => POST /api/auth/login

Channels
Get Channels => GET /api/channels
Create Channel => POST /api/channels
Update Channel => PUT /api/channels/:id
Delete Channel => DELETE /api/channels/:id

Live Streams
Get Live Streams => GET /api/streams
Create Stream => POST /api/streams

Videos
Get Videos => GET /api/videos
Upload Video => POST /api/videos
Delete Video => DELETE /api/videos/:id

News 
Get News => GET /api/news
Create News => POST /api/news
Update News => PUT /api/news/:id
